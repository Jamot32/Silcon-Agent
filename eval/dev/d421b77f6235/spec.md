I want a small RTL design with the following behavior. A VGA-style reduced-resolution raster timing generator with signed 12-bit coordinates. Active area 32x24; horizontal front/sync/back porches 3/4/5 pixels, vertical 2/2/3 lines. Coordinates run from negative blanking through active coordinate 0 to H_RES-1/V_RES-1, then wrap. Keep the signed coordinates internal. Register hsync,vsync,de,frame,line from the same previous internal coordinate each clock (one pipeline stage). de is 1 only in active area, line pulses on first coordinate of each complete line, frame pulses at first coordinate of a frame. Sync polarity is 0: hsync active for negative x in the sync interval after the front porch; likewise vsync for negative y. Synchronous rst_n=0 sets coordinates to start of negative blanking, de/frame/line=0 and sync inactive. This is a small custom raster, not a claim of standard 640x480 output.

Exact interface: module `chip`, rising-edge `clk`, active-low `rst_n`; output hsync, output vsync, output de, output frame, output line.
Fixed configuration (implement these values; parameters with these defaults are optional): CORDW=12, H_RES=32, V_RES=24, H_FP=3, H_SYNC=4, H_BP=5, V_FP=2, V_SYNC=2, V_BP=3, H_POL=0, V_POL=0.
Use synthesizable Verilog-2005. Target 25 MHz. No analog behavior is requested.
