An 8-data-bit UART receiver: low start bit, LSB-first data, high stop bit, no parity, 16 clocks per bit. Reject false starts shorter than a quarter bit. Deliver a correctly sampled byte with m_axis_tvalid after the stop sample, no later than 40 clocks after the complete frame, and hold valid/data until a ready handshake. busy must cover data reception and clear within 40 clocks after a valid frame. A bad low stop produces exactly one one-clock frame_error pulse and no accepted bad byte. Recovery after a framing error without reset is unspecified; the caller resets before resuming traffic. If a second complete byte arrives while the previous byte is still pending, replace it with the latest byte and pulse overrun_error for one clock. Do not report overrun for ordinary already-consumed bytes. Synchronous active-low rst_n clears valid, busy, errors and data, discards a partial frame, and returns to idle-high input search. No configurable baud input is needed.

Exact interface: module `chip`, rising-edge `clk`, active-low `rst_n`; output m_axis_tdata[7:0], output m_axis_tvalid, input m_axis_tready, input rxd, output busy, output overrun_error, output frame_error.
Use synthesizable Verilog-2005. Target 25 MHz.
